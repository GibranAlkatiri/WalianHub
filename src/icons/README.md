# Ikon

File SVG di folder ini disalin dari dua sumber berlisensi terbuka, supaya proyek tidak perlu memasang paket ikon:

- **Lucide** (https://lucide.dev), dari paket `lucide-static` versi 1.48.0. Lisensi ISC, sebagian ikon turunan Feather berlisensi MIT. Teks lisensi lengkap ada di `LICENSE-lucide.txt`.
- **Simple Icons** (https://simpleicons.org): `whatsapp`, `facebook`, `instagram`, `youtube`, `tiktok`. Lisensi CC0 1.0 (`LICENSE-simple-icons.md`). Logo merek tetap milik pemiliknya masing-masing.

**Menambah ikon baru:** cari ikon di https://lucide.dev, unduh file SVG-nya, simpan di folder ini dengan nama aslinya (misalnya `map-pin.svg`), lalu panggil lewat komponen `Icon` dengan nama tersebut.
