Masuk Panel Konten

Khusus pengelola konten kelurahan. Tidak perlu akun GitHub — cukup username dan password dari penanggung jawab teknis.

Baru pertama kali?

  1. Masuk dengan username dan password kelurahan.
  2. Pilih menu Layanan, Destinasi, atau Pengumuman untuk mengubah isi website.
  3. Klik Simpan sebagai draf, lalu Terbitkan jika sudah benar.

Butuh bantuan? Hubungi penanggung jawab teknis kelurahan.
